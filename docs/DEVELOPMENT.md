# Development guide

## Environment variables

Copy `.env.example` to `.env` at the repository root. Real environment
variables override `.env`. Never commit `.env`. Every variable is documented
inline in `.env.example`; only variables the code actually reads are listed.

## Backend

```bash
cd backend
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/alembic upgrade head
.venv/bin/uvicorn app.main:app --reload
```

- OpenAPI UI: `/docs` · schema: `/api/v1/openapi.json`
- Liveness: `GET /api/v1/health` · readiness (DB + PostGIS + Redis):
  `GET /api/v1/health/ready` (503 when the database or PostGIS is missing)

### Migrations

```bash
make migration m="add properties"   # autogenerate from models
make migrate                         # apply
```

Review every autogenerated migration. Keep them plain PostgreSQL/PostGIS —
no provider-specific features. `tests/test_migrations.py` fails if models and
migrations differ or a migration cannot be downgraded.

### Tests

```bash
make test-backend
```

Tests marked `db` need PostGIS (`DATABASE_URL`). Locally they are skipped if
the database is unreachable; CI sets `REQUIRE_DB=1` so they can never be
silently skipped there. There is deliberately no SQLite fallback.

## Frontend

```bash
cd frontend
npm install
npm run dev
```

- `npm test` — vitest + Testing Library
- `npm run lint`, `npm run typecheck`, `npm run format:check`
- `npm run build` — production build (standalone server)

### i18n and RTL

- Strings live in `src/i18n/dictionaries/{ar,en}.ts`. Arabic is the source of
  truth; a test enforces that English has exactly the same keys.
- Use logical utilities (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`,
  `border-s`) instead of `ml-`/`mr-`/`left-`/`right-`.
- Show API errors with `errorMessage(dict, error.code)`, never raw messages.

## Docker

```bash
docker compose up --build                                            # production-like
docker compose -f docker-compose.yml -f docker-compose.dev.yml up    # hot reload
docker compose --profile automation up                               # + n8n
```
